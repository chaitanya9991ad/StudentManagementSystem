Student Management System

The Student Management System is a Spring Boot backend application designed to manage student records through secure authentication and role-based access control. It enables administrators to manage students efficiently while providing students with secure access to their information using JWT authentication.

Features
Secure user authentication and authorization using JWT.
Role-based access control for Admin and Student.
Student registration and login.
CRUD operations for student records.
Student profile management.
RESTful APIs for managing student data.
Input validation and exception handling.
Database integration using MySQL and Spring Data JPA.
API testing with Postman.
